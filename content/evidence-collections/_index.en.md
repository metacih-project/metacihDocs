#### Naming Conventions

- - -

Entries are ordered alphabetically by indication. An additional specification is provided after a colon if datasets focus on a specific comparison or other subset.

<br>

#### Repository

- - -

Each released evidence collection has an associated **[Github repository](https://github.com/metacih-project)** in which the latest and all previous versions of the evidence collection are stored. The repository also contains a folder called `metadata`, in which additional information is provided for each release.

<br>

#### Digital Object Identifier

- - -

Each released evidence collection is automatically indexed using **[Zenodo](https://www.zenodo.org)**. In the documentation entries, a Digital Object Identifier (**[DOI](https://en.wikipedia.org/wiki/Digital_object_identifier)**) is provided, which will always resolve to the latest version of the evidence collection (see "Evidence Collection DOI"). In the "Browse all versions" section, you can access previous versions of the evidence collection. These previous versions are also provided with a unique DOI in case you want to reference a specific version in the past.
